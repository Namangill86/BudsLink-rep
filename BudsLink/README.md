# BudsLink: OnePlus Buds Companion
Create a new SwiftUI iOS 17+ app in Xcode, add these files, enable Bluetooth (NSBluetoothAlwaysUsageDescription) in Info.plist.
Implemented: BLE scan/connect/battery/RSSI, capability registry, 9-band EQ, software immersive audio + phone-sensor head follow,
App Intents, compatibility screen. Next: Find-earbuds map (MapKit/CoreLocation), camera remote (AVCaptureEventInteraction),
translation (Speech + Translation framework), privacy dashboard, onboarding, listening-level (HealthKit headphone audio levels).
